# Campus Sphere

An interactive web application designed to streamline campus management, student communication, and event tracking. Built for Wooble Hackathon Hustlehub 2026.

## Features
- Real-time campus updates and announcements
- Responsive user interface for desktop and mobile
- Integrated server routing and data components

## Tech Stack
- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** Node.js, Express / Server API
